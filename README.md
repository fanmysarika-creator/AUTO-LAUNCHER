# AutoLauncher

Android-приложение: список установленных приложений, у каждого — выбор автоматизации и кнопка «Запустить». Сверху: «Настройки» (включение сервиса) и «Стоп».

## Как получить APK
1. Создай репозиторий на GitHub и залей все файлы.
2. Вкладка **Actions → Build APK → Run workflow**.
3. Скачай `AutoLauncher-debug` из Artifacts, установи APK.
4. Нажми «Настройки» → Специальные возможности → AutoLauncher → включить.

## Сценарий Black Russia
Файл `Scenario.kt`. Порядок: новый аккаунт → обучение (дядя Слава) → /promo alenka → /reward (купон x2 пропускается) → /quest (скин, «Банковские услуги») → /gps → банкомат → положить на счёт → перевод на 366263.

## Калибровка (важно)
Игра на Unity не отдаёт элементы интерфейса, поэтому шаги — это тапы по долям экрана (`Step.Tap(x, y)`). Значения в файле — заготовки: включи в разработчике «Показывать касания / Расположение указателя», посмотри координаты нужных кнопок и поправь x/y (x = X / ширина, y = Y / высота). Имя пакета игры проверь в `packages`.

## Добавить новое приложение
Создай `Scenario` в `Scenarios.all` — оно появится в выпадающем списке.
